# Epochen der Wege

Ein friedliches 3D-Aufbau- und Logistikspiel für macOS (Swift, Xcode).
Du führst ein Volk von der Antike in die Moderne – Wachstum entsteht nur,
wenn Waren und Menschen physisch transportiert werden.

Inspiriert vom Genre-Mix aus Aufbauspielen, Strategiespielen und Transport-Simulationen.

## Eckdaten

- Echtzeit mit Pause und Zeitraffer
- Kein Militär, Konkurrenz nur wirtschaftlich
- Eine Region mit mehreren Städten
- Start in der Antike
